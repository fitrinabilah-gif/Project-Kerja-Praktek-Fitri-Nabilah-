📦 INSTALASI CEPAT (5 MENIT)
════════════════════════════════════════════════════════════════

LANGKAH 1: PERSIAPAN
────────────────────
✓ Download & install XAMPP dari: https://www.apachefriends.org/
✓ Jalankan XAMPP Control Panel
✓ Start "Apache" dan "MySQL"


LANGKAH 2: COPY FILE
────────────────────
✓ Copy folder "perisai-website" ke: C:\xampp\htdocs\
✓ Path lengkap: C:\xampp\htdocs\perisai-website\


LANGKAH 3: BUAT DATABASE
────────────────────────
✓ Buka browser → http://localhost/phpmyadmin
✓ Klik "New" di sidebar
✓ Nama database: perisai_db
✓ Klik "Create"
✓ Pilih database "perisai_db"
✓ Klik tab "Import"
✓ Pilih file: database.sql
✓ Klik "Go"
✓ Tunggu hingga selesai


LANGKAH 4: AKSES WEBSITE
────────────────────────
✓ Website: http://localhost/perisai-website/
✓ Admin: http://localhost/perisai-website/admin/login.php
   Username: admin
   Password: admin123


🎉 SELESAI! Website sudah siap digunakan!

⚡ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ ERROR: "Object not found"
✓ Pastikan folder ada di C:\xampp\htdocs\perisai-website\
✓ Cek Apache sudah running
✓ Akses: http://localhost/perisai-website/ (dengan slash)

❌ ERROR: "Database connection failed"
✓ Pastikan MySQL sudah running
✓ Cek database sudah dibuat: perisai_db
✓ Cek includes/config.php (username: root, password: kosong)

❌ ERROR: "Cannot login admin"
✓ Pastikan database sudah di-import
✓ Default: admin / admin123
✓ Cek tabel admin di phpMyAdmin

❌ Form tidak terkirim
✓ Cek JavaScript di browser console (F12)
✓ Pastikan file submit_form.php ada
✓ Cek koneksi database
