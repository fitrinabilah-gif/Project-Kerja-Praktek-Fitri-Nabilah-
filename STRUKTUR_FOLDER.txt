ALUR KERJA WEBSITE
==================

FRONTEND (Pengunjung):
1. User mengakses index.php
2. User melihat informasi PERISAI
3. User mengisi form pendaftaran di daftar.php
4. Data tersimpan ke database
5. User dapat mengirim pesan via form kontak
6. Pesan terkirim via AJAX ke submit_form.php

BACKEND (Admin):
1. Admin login di admin/login.php
2. Sistem validasi username & password
3. Jika valid, redirect ke dashboard.php
4. Admin melihat statistik & data
5. Admin dapat logout via logout.php


TEKNOLOGI YANG DIGUNAKAN
=========================

Backend:
- PHP 7.4+ (server-side scripting)
- MySQL (database)
- Session management (untuk admin login)

Frontend:
- HTML5 (semantic markup)
- CSS3 (styling, animations, responsive)
- JavaScript ES6+ (interactivity)
- AJAX (form submission)

Server:
- Apache web server
- .htaccess configuration
- mod_rewrite (optional)


FITUR KEAMANAN
==============

1. Password Hashing
   - Menggunakan password_hash() PHP
   - Algoritma: bcrypt

2. SQL Injection Prevention
   - Prepared statements
   - mysqli_real_escape_string()

3. XSS Prevention
   - htmlspecialchars()
   - Input sanitization

4. Session Security
   - Session untuk admin login
   - Timeout handling

5. File Protection
   - .htaccess untuk proteksi
   - Folder admin dilindungi

CARA UPDATE/MODIFIKASI
======================

Mengubah Warna:
- Edit variabel warna di css/style.css

Menambah Halaman:
- Buat file PHP baru
- Copy struktur dari index.php
- Update navigation menu

Menambah Tabel Database:
- Edit database.sql
- Tambah query CREATE TABLE
- Re-import database

Mengubah Email/Kontak:
- Edit di index.php bagian Contact Section
- Update di database jika perlu


MAINTENANCE
===========

Backup Reguler:
- Backup database via phpMyAdmin (weekly)
- Backup file via FTP/cPanel (weekly)

Update:
- Update PHP version sesuai kebutuhan
- Update security patches
- Optimize database secara berkala

Monitoring:
- Cek error logs di XAMPP
- Monitor database size
- Cek performance via browser DevTools
